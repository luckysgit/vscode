The dataset file (`capture20110810.binetflow`) comes from **Scenario 1 (Capture 42)** of the **CTU-13 Dataset** (created by the Czech Technical University / Stratosphere Laboratory).

It is a **bidirectional network flow (`binetflow`) file** generated using the network monitoring tool Argus. Rather than storing full packet payloads (like raw `.pcap` files), it contains aggregated summary records of network conversations (flows) along with security analysis labels.

---

### Columns / Fields in the File

| Column Name | Meaning & Description |
| --- | --- |
| **`StartTime`** | The exact timestamp indicating when the network flow began. |
| **`Dur`** | **Duration** of the connection/flow in seconds. |
| **`Proto`** | Network **transport protocol** used (e.g., `tcp`, `udp`, `icmp`, `arp`, `rtcp`). |
| **`SrcAddr`** | **Source IP address** (the origin host of the communication). |
| **`Sport`** | **Source port** number on the sending machine. |
| **`Dir`** | Communication **direction** (e.g., `<->` bidirectional, `->` unidirectional, `<?>` indeterminate). |
| **`DstAddr`** | **Destination IP address** (the target host or server). |
| **`Dport`** | **Destination port** number representing the service being accessed (e.g., `80` for HTTP, `53` for DNS, `13363` for custom services). |
| **`State`** | Protocol transaction/connection state (TCP flags or connection phases, such as `CON`, `FA_A`, `PA_RPA`, `SA_`). |
| **`sTos`** | Source **Type of Service** (IPv4 Quality of Service / ToS byte). |
| **`dTos`** | Destination **Type of Service** byte. |
| **`TotPkts`** | **Total number of packets** transmitted across the entire duration of the bidirectional flow. |
| **`TotBytes`** | **Total volume in bytes** exchanged during the flow (both directions combined). |
| **`SrcBytes`** | Number of **bytes sent exclusively by the source address**. |
| **`Label`** | The **classification tag** assigned by the researchers. |

---

### What Kind of Traffic Is Recorded?

This specific capture file documents real network activity combining three distinct categories of traffic:

1. **Normal / Background Traffic (`flow=Background...`):**
* Standard everyday internet traffic from the university environment (e.g., DNS queries, Google analytics calls, web browsing, NTP time synchronization).


2. **Normal User Traffic (`flow=From-Normal...`):**
* Benign traffic generated by controlled, clean host machines acting as baseline users.


3. **Malware / Botnet Traffic (`flow=From-Botnet...`):**
* Traffic produced by a real host infected with the **Neris botnet** (IP `147.32.84.165` in this scenario). This includes command-and-control (C2) communication, peer scanning, spam bursts, and remote server callbacks.
